# CONTENT STRATEGY

The Factory is a technology storytelling engine powered by GitHub.

Separate:
TOTAL STARS
CURRENT MOMENTUM
TECHNICAL QUALITY
CONTENT POTENTIAL

Track:
stars, growth, forks, contributors, commits, releases, activity, novelty, visual potential, curiosity, simplicity, story potential, audience relevance, diversity.

Formats:
1. single repository
2. multi-repository
3. comparison
4. trend/category
5. long-form deep dive

Repository count is dynamic. STORY DETERMINES REPOSITORY COUNT.

Never simply paraphrase README content.

Use:
repository → evidence → capability → story angle → hook → narrative → visuals → video
