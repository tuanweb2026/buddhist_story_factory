# GITHUB PROJECT RADAR FACTORY V2 — MASTER HANDOFF

Independent from AI NEWS FACTORY v2, but follows its proven autonomous operating model.

Mission:
Discover GitHub repositories → understand the technology → identify the story → create Shorts/long-form → internally QA → publish.

User experience:
Configure → Schedule → Factory runs end-to-end → User reviews results.

Initial target:
2–3 Shorts/day + ~1 long-form/day when sufficient valid stories exist.

Core principles:
- multi-agent
- centralized Orchestrator
- content-first
- evidence-driven
- internal QA
- automatic repair/retry
- fail-closed publishing
- scheduled operation
- resumable state
- audit trail
