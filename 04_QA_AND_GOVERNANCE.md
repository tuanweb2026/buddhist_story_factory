# QA AND GOVERNANCE

Continuous QA:
Discovery, Research, Scoring, Story, Fact, Script, Visual, Voice, Audio, Render, Final Red-Team.

Failure handling:
repair → regenerate affected artifact → retest → retry within limits → escalate only if recovery exhausted.

Fail closed if any mandatory gate is:
FAIL / UNKNOWN / MISSING / UNRESOLVED / EXPIRED / CONFLICT.

Never publish without:
valid video + metadata + fact QA + script QA + visual QA + audio QA + render QA + final red-team + duplicate check + valid authentication.

Never expose credentials/tokens.
