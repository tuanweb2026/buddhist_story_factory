# AGENT CONTRACTS

Each agent must define:
- responsibility
- input schema
- output schema
- validation
- errors
- retry policy
- audit artifact
- tests

Minimum logical agents:
Discovery, Popularity/Momentum, Repository Intelligence, Technical Analyzer, Activity/Community, Content Potential, Story Selection, Hook/Angle, Fact Verification, Script, Script QA, Visual Planning, Visual Asset, Visual QA, Voice, Audio QA, Render, Render QA, Final Red-Team, Publisher, Post-Publish Verification.

These may be Python modules/classes.
